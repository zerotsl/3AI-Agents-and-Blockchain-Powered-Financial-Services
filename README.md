# 3AI-Agents-and-Blockchain-Powered-Financial-Services
金融服务原型，模拟资金委托给 AI 代理后的情况：如何确保其支出在用户设定的范围内，以及在出现问题时如何解决后续问题。使用基于 NPU 的 Kiln API（LLM 代币 API）为代理提供支持，并将区块链集成到您选择的工作流程中。Kiln 提供低功耗 NPU 推理功能，使团队能够探索完整服务在代币使用和能耗方面的运行效率。支付系统记录了谁向谁付款，但并未记录授权人或授权条件，因此代理能够控制在预算范围内仅仅是因为其设计如此。可能的实现方案包括：用于审批、监控和停止代理支出的钱包界面；在整个会话期间维护预算和授权列表的策略层；使用审批和交易记录解释过去购买行为的工具；或其他使委托支出可追溯的方法。
